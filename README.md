# Actividad #4 Desarrollo-de-ejercicios-y-codigos-en-Google-Colab-Fundamentos-de-Python
En estos ejercicios se aplicaron los fundamentos de Python mediante Google Colab, comprendiendo su estructura y la creación de códigos. También se exploraron NumPy y Pandas como herramientas para facilitar el manejo de datos y desarrollar soluciones de forma más rápida y eficiente.
